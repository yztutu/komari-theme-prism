# Prism · 棱镜

A frosted-glass theme for [Komari Monitor](https://github.com/komari-monitor/komari).

**Live demo:** https://yztutu.github.io/komari-theme-prism/ (demo data)

Design lineage: layout DNA from **Komari Next** (MIT, by tonyliuzj), frosted-glass texture inspired by **PurCarte** (MIT, by Montia37). All code here is an original single-file implementation.

Our twists: aurora backdrop, an overview strip that includes the **nearest node expiry**, per-node tags, and a card grid that scales to any fleet size.

Install: download the theme zip from Releases and upload it in Komari admin → Themes. (Market submission pending design approval.)
